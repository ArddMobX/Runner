# Runner — Автономный Android ИИ-агент

> Мобильный автономный ИИ-агент на Kotlin + Jetpack Compose с поддержкой Tool Calling, расширенным набором инструментов, рендерингом Markdown и LaTeX формул, а также подключением любого OpenAI-совместимого провайдера (OpenRouter, Groq, DeepSeek, OpenAI и др.).

---

## ⚡ Инструменты агента (Tools)

Агент умеет автономно выполнять 14 нативных системных инструментов прямо на Android без Root:

### 1. Работа с файлами и папками
* **`write_file(path, content, append)`** — создание, запись и дозапись текстовых файлов (автоматически создает директории).
* **`read_file(path, max_lines)`** — чтение содержимого файлов с ограничением строк для экономии контекста.
* **`delete_file(path, recursive)`** — безопасное удаление файлов и папок (с защитой от случайного удаления корня памяти).
* **`create_dir(path)`** — создание новых папок со всеми промежуточными поддиректориями.
* **`move_file(source_path, destination_path)`** — перемещение и переименование файлов и папок.
* **`copy_file(source_path, destination_path)`** — быстрое копирование файлов и директорий.

### 2. Поиск и архивы
* **`search_files(query, path, extension)`** — глубокий поиск файлов по названию и расширению.
* **`create_archive(source_paths, zip_path)`** — создание `.zip` архивов из файлов и папок через Zip4j.
* **`extract_archive(zip_path, target_dir)`** — нативная распаковка ZIP-архивов.
* **`get_folder_summary(path)`** — аудит папок: подсчет документов, медиа, архивов, APK и топ-5 самых тяжелых файлов.
* **`organize_downloads(category)`** — автоматическая сортировка `Download` по типам (`documents`, `apks`, `archives`, `images`, `all`) с защитой от перезаписи при совпадении имён.

### 3. Буфер обмена
* **`clipboard_read()`** — чтение текущего содержимого системного буфера обмена.
* **`clipboard_write(text)`** — запись текста в системный буфер обмена.

### 4. Терминал (Shell)
* **`run_shell_command(command, timeout_seconds)`** — выполнение команд шелла (`sh`) на устройстве с возвратом stdout, stderr и кода возврата.

## 🎨 UI и рендеринг: Markdown & LaTeX

* **Полноценный Markdown:** заголовки, списки, цитаты, жирный текст (`**bold**`), курсив (`*italic*`), зачеркивание (`~~strike~~`).
* **Блоки кода:** с указанием языка программирования, горизонтальным скроллом и кнопкой «Копировать код».
* **Математические формулы LaTeX:**
  * Блочные формулы `$$ ... $$` рендерятся через KaTeX в темной теме приложения.
  * Inline-формулы `$ ... $` красиво стилизуются прямо внутри текста с поддержкой математических символов ($\alpha$, $\beta$, $\pi$, $\int$, $\sum$, $\sqrt{}$, $x^2$, $x_1$).

## 🌐 Универсальный OpenAI-совместимый API

Приложение не привязано к конкретному вендору. В настройках доступны:
* **Base URL** (например, `https://openrouter.ai/api/v1`, `https://api.deepseek.com`, `https://api.groq.com/openai/v1`, `https://api.openai.com/v1` или локальный Ollama).
* **API Key** соответствующего сервиса.
* **Название модели** (`deepseek-chat`, `meta-llama/llama-3.3-70b-instruct`, `gpt-4o-mini`, `llama-3.3-70b-versatile` и др.).
* Быстрые пресеты в один клик: **Groq**, **OpenRouter**, **DeepSeek**, **OpenAI**.

## 📲 Как скачать APK без Android Studio

APK автоматически собирается в облаке через **GitHub Actions**:
1. Перейдите во вкладку [Actions](https://github.com/ArddMobX/Runner/actions).
2. Откройте последний завершённый запуск сборки.
3. Внизу в блоке **Artifacts** скачайте **`Runner-Debug-APK`**.
4. Или перейдите во вкладку [Releases](https://github.com/ArddMobX/Runner/releases) и скачайте `app-debug.apk`.

## 🔑 Начало работы в приложении

1. Установите APK на смартфон (Android 8.0+).
2. Откройте экран **Настройки** (шестерёнка в правом верхнем углу):
   * Выберите провайдера пресетом или укажите свои Base URL, модель и API ключ.
   * Нажмите **«Выдать разрешение в настройках»** и включите тумблер `MANAGE_EXTERNAL_STORAGE` (*Доступ ко всем файлам*).
3. Вернитесь в чат и дайте любую задачу, например:
   * *«Сделай сводку по папке Download и найди все PDF»*
   * *«Прочитай буфер обмена и запиши текст в файл Documents/note.txt»*
   * *«Узнай свободное место на диске через shell команду df -h»*
   * *«Напиши формулу корней квадратного уравнения и поясни ее»*
