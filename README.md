# Runner — Автономный Android ИИ-агент

> Мобильный автономный ИИ-агент на Kotlin + Jetpack Compose: tool calling, 20 системных инструментов,
> стриминг ответов, рендеринг Markdown и LaTeX, история чатов и любой OpenAI-совместимый провайдер.

---

## 🧭 Как устроено

* **Бэкенда нет.** Телефон обращается к провайдеру напрямую через OkHttp. Единственное,
  что нужно, — Base URL, ключ и ID модели.
* **Провайдеры.** Несколько провайдеров одновременно: имя, Base URL, свой ключ, свой список
  моделей. Активный провайдер и модель переключаются чипом в шапке чата.
* **Список моделей тянется из `GET /models`** у самого провайдера, а не вводится руками.
  Автоподгрузка срабатывает сама через 600 мс после ввода ключа; рядом с чипом модели
  виден спиннер. Если провайдер не отдал список — в списке остаётся ручной ввод ID.
  В строке модели показываются имя, бейдж контекста и кнопка копирования ID.
* **Ключи шифруются** ключом Android Keystore (AES-256-GCM). В открытом виде на диск не попадают.
  Если Keystore недоступен, список провайдеров уходит в незашифрованный резерв
  `providers_blob_plain` — это осознанный компромисс, чтобы не терять настройки, а не норма.
* **Резервное копирование выключено** (`allowBackup="false"`): в SharedPreferences лежат
  API-ключи, и в Google-бэкап они попадать не должны.
* **Подтверждение опасных действий.** Удаление, перезапись, перемещение, копирование,
  архивы, сортировка, shell, запись в буфер и запуск приложений/ссылок требуют подтверждения.
  Утверждённый план больше не «предодобряет всё»: сверяются не только имена инструментов,
  но и аргументы, которые были в показанном шаге.
* **Недоверенный вывод помечен.** Содержимое `read_file`, `list_dir` и `clipboard_read`
  приходит в конверте «НЕДОВЕРЕННЫЕ-ДАННЫЕ»: это данные, а не инструкции для агента.
* **История чатов** хранится в Room: боковое меню со списком сессий, поиском и удалением.
  Контекст диалога сохраняется целиком, поэтому агент продолжает работу после перезапуска.
* **Бюджет контекста** — настроен в «Настройки → Агент». Старые реплики отбрасываются
  перед отправкой, хвост диалога и системный промпт сохраняются: длинная сессия не
  упирается в лимит модели.
* **Стриминг** — текст ответа появляется по мере генерации, кнопка отправки превращается в «Стоп».
* **Статистика** (отключается в настройках): под ответом — общее время задачи, токены
  вход/выход и скорость генерации; в карточке инструмента — время самой операции;
  у thinking-моделей — счётчик «Думал X сек» с размышлениями под катом.
* **Нижняя панель** — пилюля на surface-container, авто-растущее поле до 5 строк без системных
  рамок, круглая кнопка со стрелкой: неактивна при пустом поле, окрашивается акцентом при вводе,
  превращается в стоп во время работы.
* **Human-in-the-Loop** — удаление, перемещение, запись, сортировка и shell требуют подтверждения,
  с превью того, что именно будет затронуто.

## ⚡ Инструменты агента (20 штук)

Работают на устройстве без Root. Файловые инструменты заперты внутри
`/storage/emulated/0` — за его пределы не выйти ни относительным путём, ни `..`.

### 1. Работа с файлами и папками
* **`list_dir(path, limit)`** — список файлов и папок в директории.
* **`read_file(path, max_lines)`** — чтение файлов с ограничением строк для экономии контекста.
* **`write_file(path, content, append)`** — создание, запись и дозапись текстовых файлов.
* **`delete_file(path, recursive)`** — удаление файлов и папок (с защитой от удаления корня памяти).
* **`create_dir(path)`** — создание папок со всеми промежуточными поддиректориями.
* **`move_file(source_path, destination_path)`** — перемещение и переименование.
* **`copy_file(source_path, destination_path)`** — копирование файлов и директорий.

### 2. Поиск и архивы
* **`search_files(query, path, extension)`** — глубокий поиск по названию и расширению.
* **`create_archive(source_paths, zip_path)`** — создание `.zip` через Zip4j.
* **`extract_archive(zip_path, target_dir)`** — распаковка ZIP-архивов.
* **`get_folder_summary(path)`** — аудит папки: категории, объёмы, топ-5 тяжёлых файлов.
* **`organize_downloads(category)`** — сортировка `Download` по типам с защитой от перезаписи.

### 3. Аналитика памяти
* **`get_storage_summary()`** — всего/занято/свободно плюс вес категорий.
* **`find_largest_files(limit, min_size_mb)`** — самые тяжёлые файлы на устройстве.
* **`find_junk_files()`** — временные файлы и пустые папки.

### 4. Буфер обмена и терминал
* **`clipboard_read()`** / **`clipboard_write(text)`** — системный буфер обмена.
* **`run_shell_command(command, timeout_seconds)`** — команды `sh` с возвратом stdout, stderr и кода.
  Пока в настройках выключен тумблер «Shell вне памяти», команды с путями в `/data`,
  `/system`, `/proc`, `/dev`, `/sys`, `/vendor`, `/apex` отклоняются; `df -h`, `ls /sdcard`,
  `du -d 1`, `pm list packages` работают как обычно.

### 5. Запуск приложений и ссылок
* **`open_app(app)`** — запуск приложения по названию или пакету.
* **`open_url(url)`** — открытие ссылки в браузере или приложении, которое её обрабатывает.

> `open_app` ищет приложение по названию, а для этого на Android 11+ нужен
> `QUERY_ALL_PACKAGES`: без него `queryIntentActivities` возвращает только свои
> пакеты. Разрешение чувствительное, поэтому приложение распространяется сайдлоадом,
> а не через Google Play.

## 🎨 UI и рендеринг: Markdown & LaTeX

* **Полноценный Markdown:** заголовки, списки, цитаты, `**bold**`, `*italic*`, `~~strike~~`.
* **Блоки кода:** с языком, горизонтальным скроллом и кнопкой «Копировать».
* **LaTeX:** блочные `$$ ... $$` через KaTeX, строчные `$ ... $` прямо в тексте.
* **Карточки вызовов инструментов** — одна сворачиваемая строка вида
  «Сканирую Download · 143 файла», детали по нажатию.

## 🌐 Универсальный OpenAI-совместимый API

Приложение не привязано к конкретному вендору. На экране **Настройки → Провайдеры** можно
держать сколько угодно провайдеров сразу; у каждого своё имя, Base URL, свой ключ и свой список моделей.

### Где взять ключ

| Провайдер | Ключ | Base URL | Бесплатно |
|---|---|---|---|
| Groq | console.groq.com/keys | `https://api.groq.com/openai/v1` | 30 RPM / 1000 RPD / 8K TPM / 200K TPD, карта не нужна |
| Gemini | aistudio.google.com/app/apikey | `https://generativelanguage.googleapis.com/v1beta/openai` | Есть, карта не нужна; лимиты — в AI Studio → Rate limits |
| OpenRouter | openrouter.ai/keys | `https://openrouter.ai/api/v1` | Модели с суффиксом `:free` — 20 RPM / 50 RPD (1000 RPD после $10) |
| DeepSeek | platform.deepseek.com/api_keys | `https://api.deepseek.com` | Нет, но дёшево ($0.15/$0.60 за 1M off-peak) |
| OpenAI | platform.openai.com/api-keys | `https://api.openai.com/v1` | Нет |

### Про ID моделей

В коде лежит только **стартовый** список на случай, если провайдер ещё не отдал свой:
он неизбежно устаревает. Настоящий список тянется кнопкой обновления из `GET /models`
у самого провайдера, и первый же запуск это показывает. Ориентироваться на конкретные ID
из README бессмысленно — сверяйтесь с ответом провайдера.

На момент правки кода стартовые значения были такие:

| Провайдер | Стартовые ID |
|---|---|
| Groq | `openai/gpt-oss-120b`, `openai/gpt-oss-20b`, `qwen/qwen3.8-27b` |
| Gemini | `gemini-2.5-flash`, `gemini-2.5-flash-lite`, `gemini-2.5-pro` |
| OpenRouter | `qwen/qwen3.8-27b:free`, `nvidia/nemotron-3.5-lightning:free`, `deepseek/deepseek-v4.1-flash` |
| DeepSeek | `deepseek-flash`, `deepseek-v4-pro` |
| OpenAI | `gpt-5.4-nano`, `gpt-6-luna`, `gpt-6-astra` |

Учтите: у Gemini стартовый список и то, что рекомендовала документация, разошлись —
в коде `gemini-2.5-*`, в текстах фигурировал `gemini-3.8-flash`. Если провайдер
отвечает 404, дело почти всегда в ID модели, а не в Base URL.

> ID моделей у провайдеров меняются: `llama-3.3-70b-versatile` снят 16.08.2026,
> `deepseek-chat` — 24.07.2026. Живой каталог OpenRouter отдаёт без авторизации:
> `https://openrouter.ai/api/v1/models` (`id`, `context_length`, `pricing`,
> `supported_parameters` — наличие `tools` обязательно, иначе агент не заработает).

> Бесплатные модели OpenRouter у DeepSeek, NVIDIA, Liquid и Thinking Machines
> могут использоваться для обучения — агент читает файлы и буфер обмена, учитывай это.

## 📲 Как скачать APK без Android Studio

APK автоматически собирается в облаке через **GitHub Actions**.

**Готовые релизы** — вкладка [Releases](https://github.com/ArddMobX/Runner/releases):
файл `Runner-1.0.<номер>-release.apk` и рядом `.sha256` для проверки целостности.
Релиз подписан ключом проекта, поэтому устанавливается поверх предыдущих версий
и не требует удаления приложения.

**Debug-сборка** каждой ревизии лежит в артефактах прогона:
[Actions](https://github.com/ArddMobX/Runner/actions) → нужный прогон → блок
**Artifacts** → `Runner-Debug-APK-<номер>` (это zip, внутри APK и `.sha256`).
Важно: артефакты GitHub отдаёт **только авторизованным**, в отличие от релизов.
Debug-сборка не публикуется как релиз: у неё общеизвестный отладочный ключ,
а `debuggable=true` позволяет вытащить расшифрованный API-ключ через adb.

### Подпись релизов: что должно быть настроено

Релизы собираются только при наличии ключа. Он хранится в GitHub-среде
**`release-signing`** (Settings → Environments), а не в общих секретах
репозитория: workflow срабатывает на пуш в любую ветку, и ключ, доступный
всегда, позволил бы подписать своим кодом APK, неотличимый для системы
обновлений. Пока среды нет, собирается только debug.

В этой среде нужны четыре секрета:

| Секрет | Что это |
|---|---|
| `KEYSTORE_BASE64` | keystore, закодированный в base64 |
| `KEYSTORE_PASSWORD` | пароль хранилища |
| `KEY_ALIAS` | имя ключа |
| `KEY_PASSWORD` | пароль ключа |

Если ключ потерян, обновить уже установленное приложение не получится:
Android отвергнет APK с другим сертификатом. Храните копию в надёжном месте.

Локально те же значения можно положить в `~/.gradle/gradle.properties`
под именами `RUNNER_KEYSTORE_PATH`, `RUNNER_KEYSTORE_PASSWORD`,
`RUNNER_KEY_ALIAS`, `RUNNER_KEY_PASSWORD`. Без них `assembleRelease` падает с
понятным сообщением, а `assembleDebug` работает как обычно.

## 🔑 Начало работы в приложении

1. Установите APK на смартфон (Android 8.0+).
2. Откройте боковое меню (иконка слева в шапке) → **Настройки → Провайдеры**, выберите
   провайдера и вставьте ключ. Кнопка обновления рядом со списком моделей подтянет их
   из `GET /models` — вводить ID руками не нужно.
3. **Настройки → Доступы** → «Открыть системные настройки» и включите
   *Доступ ко всем файлам*. Тумблер в приложении право не выдаёт, это делает только
   системный экран.
4. Вернитесь в чат, нажмите на чип модели в шапке и выберите модель. Затем дайте задачу:
   * *«Сделай сводку по папке Download и найди все PDF»*
   * *«Прочитай буфер обмена и запиши текст в файл Documents/note.txt»*
   * *«Узнай свободное место на диске через shell команду df -h»*
   * *«Напиши формулу корней квадратного уравнения и поясни ее»*

Долгие задачи можно прервать кнопкой **«Стоп»** — уже сгенерированная часть ответа сохранится.
