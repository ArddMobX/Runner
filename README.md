# Runner

Автономный Android-агент с tool calling. Работает без бэкенда: приложение обращается к любому OpenAI-совместимому провайдеру напрямую.

## Что умеет

- 34 инструмента: файлы, поиск, архивы, память, shell, буфер обмена, звонки, контакты, интернет и управление экраном.
- Несколько провайдеров с отдельными ключами и списками моделей. Список моделей тянется из `GET /models`.
- Стриминг ответов, Markdown, LaTeX через KaTeX, подсветка кода.
- Ход задачи: реплики модели, план и шаги инструментов в одной ленте, с временем и раскрываемыми деталями.
- Изменения файлов показываются карточками: создан, изменён, удалён, перемещён; строки +/−, размер, дифф и отмена.
- История чатов в Room: поиск по названию и содержимому, закрепление, переименование.
- Подтверждения опасных действий: план, аргументы, diff, галочки по файлам.
- Обратимые операции: корзина, откат удаления, перемещения и перезаписи.
- Режимы "только чтение", сухой прогон, автономный режим в рабочей папке.
- Live-режим: accessibility, плавающая карточка, `ui_*` инструменты только при включённом режиме. `open_app` фиксирует целевое приложение, действия в чужом окне блокируются. Есть план с критерием успеха, пауза/продолжить и режим подтверждения каждого шага. Лимит шагов настраивается, по умолчанию без ограничения: остановить задачу можно кнопкой «Стоп».
- Уведомления о завершении, ошибке и запросе подтверждения.
- Vision: до 10 изображений. STT и TTS на системных службах Android.
- Интернет: `web_search` и `web_fetch`. Поиск работает через DuckDuckGo без настройки, ключ Tavily в настройках делает выдачу стабильнее. Под карточкой инструмента появляется строка источников со шторкой.
- Плитка Quick Settings, плавающее окно, захват экрана.

## Безопасность

- API-ключи шифруются через Android Keystore (AES-256-GCM). Если Keystore недоступен, используется незашифрованный резерв, чтобы не потерять настройки. Это компромисс, а не норма.
- `allowBackup=false`: ключи не попадают в Google-бэкап.
- Опасные действия требуют подтверждения. "Больше не спрашивать" запоминает конкретную операцию, а не инструмент целиком.
- Текст из `read_file`, `list_dir`, `clipboard_read`, `web_search` и `web_fetch` помечается как недоверенный. Если аргументы операции совпали с этим текстом, подтверждение спрашивается даже при снятых галочках.
- Удаление, перемещение и перезапись откатываются через журнал `.runner-trash`. Дозапись (`append`) необратима.
- Shell заперт в `/storage/emulated/0`. `su` и катастрофические команды (`pm clear`, `uninstall`, `wipe`, `mkfs`, `dd` на устройство) запрещены по умолчанию.
- Live-режим блокирует банковские приложения и поля ввода паролей. `ui_click` по координатам и `ui_type` без полного доступа требуют подтверждения.

## Инструменты

**Файлы:** `list_dir`, `read_file`, `write_file`, `delete_file`, `create_dir`, `move_file`, `copy_file`.

**Поиск и архивы:** `search_files`, `create_archive`, `extract_archive`, `get_folder_summary`, `organize_downloads`.

**Память:** `get_storage_summary`, `find_largest_files`, `find_junk_files`.

**Система:** `clipboard_read`, `clipboard_write`, `run_shell_command`.

**Запуск:** `open_app`, `open_url`.

**Связь:** `call_phone`, `search_contacts`.

**Интернет:** `web_search`, `web_fetch`. Только http/https, внешние адреса; localhost, домашняя сеть и `file://` отклоняются.

**Live:** `ui_inspect`, `ui_click`, `ui_long_click`, `ui_type`, `ui_scroll`, `ui_global_action`, `ui_wait`, `ui_wait_for`, `ui_target`, `ui_finish`.

`delete_file` не удаляет, а переносит в корзину. `move_file` не перезаписывает существующую цель. `run_shell_command` использует Toybox: короткие флаги, без GNU-опций вроде `--max-depth`.

## Провайдеры

Настройки -> Провайдеры. Для каждого провайдера нужны Base URL, ключ и модель.

| Провайдер | Base URL | Ключ |
|---|---|---|
| Groq | `https://api.groq.com/openai/v1` | console.groq.com/keys |
| Gemini | `https://generativelanguage.googleapis.com/v1beta/openai` | aistudio.google.com/app/apikey |
| OpenRouter | `https://openrouter.ai/api/v1` | openrouter.ai/keys |
| DeepSeek | `https://api.deepseek.com` | platform.deepseek.com/api_keys |
| OpenAI | `https://api.openai.com/v1` | platform.openai.com/api-keys |

Настоящий список моделей приходит из `GET {base}/models`. Стартовые ID в коде - только подсказка; они устаревают, поэтому проверяйте список у провайдера. Если модель отвечает 404, скорее всего изменился её ID, а не Base URL.

Для агента модель должна поддерживать tool calling. Бесплатные модели OpenRouter могут использовать запросы для обучения, а агент читает файлы и буфер обмена.

## Сборка

- Android 8.0+ (minSdk 26), targetSdk 35, JDK 17.
- Debug: `./gradlew assembleDebug`. APK и `.sha256` появятся в `app/build/outputs/apk/debug`.
- Release: `./gradlew assembleRelease`. Нужны `RUNNER_KEYSTORE_PATH`, `RUNNER_KEYSTORE_PASSWORD`, `RUNNER_KEY_ALIAS`, `RUNNER_KEY_PASSWORD` в `~/.gradle/gradle.properties`.
- GitHub Actions собирает debug всегда, release только если в среде `release-signing` заданы `KEYSTORE_BASE64`, `KEYSTORE_PASSWORD`, `KEY_ALIAS`, `KEY_PASSWORD`.
- Готовые APK лежат в Releases. Debug-сборки - в артефактах Actions и доступны только авторизованным.
- Потеря ключа подписи означает, что обновить установленное приложение уже не получится.

## Быстрый старт

1. Установить APK.
2. Настройки -> Провайдеры: выбрать провайдера, вставить ключ, обновить список моделей.
3. Настройки -> Доступы: выдать "Доступ ко всем файлам" на системном экране.
4. Вернуться в чат, выбрать модель и дать задачу.

Примеры:

- "Сделай сводку по папке Download и найди все PDF".
- "Прочитай буфер обмена и запиши текст в Documents/note.txt".
- "Сколько свободно на диске? Проверь через df -h".
- "Открой YouTube и найди котиков".

Долгую задачу можно остановить кнопкой "Стоп": уже сгенерированная часть ответа сохранится.
